Lab 09 – JavaScript 2: DOM and Events

Truy cập và thay đổi DOM, tạo/xóa phần tử, xử lý sự kiện, gỡ lỗi, biểu mẫu và kiểm tra dữ liệu.

Basic DOM Selection

Chọn phần tử bằng getElementById, getElementsByTagName, getElementsByClassName, querySelector và querySelectorAll; đọc/sửa value, innerHTML, innerText, thuộc tính class và style.backgroundColor.
