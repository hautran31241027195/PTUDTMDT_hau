Enabling / Disabling JavaScript

You have JavaScript disabled

Cách thực hiện

  1. Mở trang này khi JavaScript bật → hiện “You have JavaScript enabled”.
  2. Tắt JavaScript (Chrome: Settings → Privacy and security → Site settings → JavaScript, hoặc DevTools → Ctrl+Shift+P → “Disable JavaScript”), tải lại trang → hiện “You have JavaScript disabled”.
  3. Thử trang gốc của đề bài: examples.funwebdev.com/JavaScriptTest.php
